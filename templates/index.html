Frequently Asked Questions

Clear answers to common questions about InsightFlow's data processors.

Is my data secure in the private database?

Yes. Every project metadata payload is stored securely inside a private, user-isolated relational SQLite database. Files are never shared publicly.

What file formats does the upload tool accept?

We support standard tables: CSV (comma-separated), TSV (tab-separated), Excel (.xlsx, .xls), and structured JSON list arrays.

How does the dynamic outcome simulator compute forecasts?

It fits a live Random Forest regressor or classifier to the training targets, then streams real-time feature coordinates to calculate predictions synchronously.
